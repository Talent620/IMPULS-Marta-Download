IMPULS DOTACJE MARTA 4.2.5 RC1 — PIERWSZE URUCHOMIENIE

To jest wydanie testowe RC.

1. Pobierz wyłącznie plik:
   IMPULS-Dotacje-Marta-4.2.5-rc.1-Setup.exe

2. Zamknij wcześniejszą wersję programu i uruchom instalator.
   Aktualizacja używa tej samej nazwy programu i tego samego katalogu danych.

3. Instalator nie ma potwierdzonego podpisu zaufanego wydawcy.
   Nie wyłączaj antywirusa ani ochrony Windows. Jeżeli zasady komputera
   blokują uruchomienie, zatrzymaj instalację i pokaż komunikat właścicielowi.

4. W programie kliknij „Ustawienia i kopie”, a potem „Uruchom AI”.
   Przejdź cztery kroki widoczne w aplikacji:
   konto i płatności API → wklejenie klucza → wybór AI → limit i krótki test.

5. Po komunikacie „AI działa. Możesz rozpocząć rozmowę” kliknij
   „Przejdź do Marta AI”.

ChatGPT Plus/Pro i API są rozliczane oddzielnie. Wpisanie limitu w Marcie
nie kupuje środków OpenAI. Klucza nie wysyłaj programiście ani w rozmowie.

Kopia JSON w ustawieniach jest kopią bazy, a nie wszystkich załączników
i rozmów. Do przenoszenia całej pracy zachowaj również folder danych przy
zamkniętej aplikacji; na nowym komputerze skonfiguruj klucz ponownie.
